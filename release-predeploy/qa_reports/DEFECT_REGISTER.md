| **DEF-001** | Critical / Blocker | Authentication / Navigation | `AuthGate` full-screen loading hijack unmounts `LoginScreen` during login submission, causing UI flash and loss of error snackbar | 1. Open app.<br>2. Submit login or tap demo account.<br>3. `AuthGate` replaces `LoginScreen` with full-screen spinner.<br>4. On failure/timeout, `LoginScreen` remounts from scratch, dropping error snackbar (`mounted == false`). | `_isLoading` in `AuthProvider` was overloaded for both initial cold-boot session loading and active form submission. `AuthGate` watched `_isLoading` and tore down the login view. | Separated state into `_isInitializingSession` (for cold boot) and `_isSubmittingLogin`. `AuthGate` only gates on `_isInitializingSession`. `LoginScreen` manages inline progress on the button. | `AuthProvider separates isInitializingSession from isSubmittingLogin and allows skip` in `test/production_fix_verification_test.dart` | **RESOLVED** |
| **DEF-002** | High | App Startup / Splash | App stuck indefinitely on splash screen if offline or server is unreachable during cold boot | 1. Launch app with previous token saved when outside office Wi-Fi.<br>2. App calls `getMe()` with 15s timeout.<br>3. Splash screen had no cancel or server config option. | `AuthGate` had no timeout escape hatch or manual skip action while session verification was pending. | Added "Continue to Login Screen" and `cancelOrSkipInitialization()` to `AuthGate` so users are never trapped on splash. | `cancelOrSkipInitialization` test in `test/production_fix_verification_test.dart` | **RESOLVED** |
